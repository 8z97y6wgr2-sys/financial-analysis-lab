# Portfolio theory

Status: topic guide; worked models pending.

## Core framework

Expected portfolio return = sum(w_i × expected return_i). Variance = w^T × covariance matrix × w. Sharpe = excess return / volatility under matching conventions.

## Exercise format

State the question, data provenance or synthetic label, units, assumptions, calculation steps, interpretation and verification. No solved example or empirical result is claimed in this folder yet.

## Limitations

Correlations and expected returns are estimates. Separate historical analytics from forecasts and use consistent annualization.

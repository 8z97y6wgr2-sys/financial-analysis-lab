# Financial statements

Status: topic guide; worked models pending.

## Core framework

Connect income statement, balance sheet and cash flow. CCC = days inventory outstanding + days sales outstanding - days payables outstanding.

## Exercise format

State the question, data provenance or synthetic label, units, assumptions, calculation steps, interpretation and verification. No solved example or empirical result is claimed in this folder yet.

## Limitations

Distinguish earnings from collected cash. Reconcile statement periods and ratio denominators before interpreting liquidity or operating efficiency.

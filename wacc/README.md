# WACC

Status: topic guide; worked models pending.

## Core framework

WACC = E/(D+E) × Ke + D/(D+E) × Kd × (1-T), for the simple debt/equity case.

## Exercise format

State the question, data provenance or synthetic label, units, assumptions, calculation steps, interpretation and verification. No solved example or empirical result is claimed in this folder yet.

## Limitations

Use market-value weights. Separate debt cost before tax from after-tax cost; keep currency and cash-flow basis consistent.

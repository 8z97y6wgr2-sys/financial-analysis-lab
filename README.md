# Financial Analysis Lab

An academic and professional finance laboratory for focused exercises, transparent formulas and small financial models that do not require separate repositories.

## Project Status

**Initial documentation and exercise framework.** Topic guides are available; no solved notebook, executable model, spreadsheet or verified company analysis has been imported. This repository supports the research projects without duplicating their source code or reports.

## Topics

| Folder | Focus |
| --- | --- |
| `capm/` | Cost of equity, beta and market risk premium |
| `wacc/` | Capital weights and after-tax debt cost |
| `roic-eva/` | Capital efficiency, spread and economic value added |
| `financial-statements/` | Statement links, ratios and cash conversion |
| `valuation-multiples/` | Equity/enterprise value and comparable multiples |
| `portfolio-theory/` | Diversification, covariance, volatility and Sharpe |
| `corporate-finance/` | Capital budgeting, cash flow and value creation |

## Methodology

Each future exercise should state its question, source or synthetic-data label, units, assumptions, formulas, worked calculation, interpretation and limitations. Separate teaching examples from observed company data. Reconcile intermediate outputs and avoid rounding until presentation. Small exercises belong here; full equity research, software and quantitative systems belong in their dedicated repositories.

## Tech Stack

Current: Markdown and Git. Planned as needed: Python, spreadsheets, notebooks and Power BI. No package installation or execution is required for the existing guides.

## Usage

Choose a topic guide and add a sourced model or a clearly labeled synthetic exercise. When adding code, include its actual dependencies and run instructions alongside the exercise.

## Limitations

The guides are learning frameworks rather than completed empirical studies or investment recommendations. CAPM, WACC and valuation conclusions depend on the assumptions and data chosen; favorable financial ratios alone do not establish an attractive investment.

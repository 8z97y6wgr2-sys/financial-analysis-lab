# ROIC and EVA

Status: topic guide; worked models pending.

## Core framework

ROIC = NOPAT / invested capital; spread = ROIC - WACC; EVA = NOPAT - WACC × invested capital.

## Exercise format

State the question, data provenance or synthetic label, units, assumptions, calculation steps, interpretation and verification. No solved example or empirical result is claimed in this folder yet.

## Limitations

Define the capital base and period consistently. A lower ROIC can still create value above WACC; evaluate marginal investment against its cost of capital.

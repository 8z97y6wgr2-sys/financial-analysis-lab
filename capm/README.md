# CAPM

Status: topic guide; worked models pending.

## Core framework

Cost of equity = risk-free rate + beta × market risk premium. The market premium is expected market return minus the risk-free rate.

## Exercise format

State the question, data provenance or synthetic label, units, assumptions, calculation steps, interpretation and verification. No solved example or empirical result is claimed in this folder yet.

## Limitations

Use compatible currency, horizon and rate conventions. Distinguish historical beta estimates from future risk assumptions.

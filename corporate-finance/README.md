# Corporate finance

Status: topic guide; worked models pending.

## Core framework

NPV discounts incremental project cash flows at a rate appropriate to their risk. FCFF and FCFE use different financing treatments and discount rates.

## Exercise format

State the question, data provenance or synthetic label, units, assumptions, calculation steps, interpretation and verification. No solved example or empirical result is claimed in this folder yet.

## Limitations

Separate incremental cash flow from sunk costs. Document working capital, taxes, reinvestment, terminal assumptions and scenario sensitivity.

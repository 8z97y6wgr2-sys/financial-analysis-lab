# Valuation multiples

Status: topic guide; worked models pending.

## Core framework

P/E = share price / EPS. EV/EBITDA = enterprise value / EBITDA. A simplified equity bridge is equity value = EV - debt + cash, with other claims assessed separately.

## Exercise format

State the question, data provenance or synthetic label, units, assumptions, calculation steps, interpretation and verification. No solved example or empirical result is claimed in this folder yet.

## Limitations

Use comparable periods, accounting definitions and capital structures. A low multiple alone does not establish undervaluation.
